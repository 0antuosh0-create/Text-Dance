# پرامپت‌موشن استودیو

پرامپت‌موشن استودیو یک برنامه کاملا آفلاین در مرورگر است که از یک متن یا پرامپت، ویدیوهای کوتاه موشن‌گرافیک می‌سازد. تمام فریم‌ها روی Canvas ساخته می‌شوند، صدا داخل مرورگر ترکیب می‌شود، و خروجی به صورت فایل ویدیویی قابل دانلود آماده می‌شود.

## امکانات

- ساخت ویدیو از پرامپت همراه با پیش‌نمایش زنده
- ۱۳ سبک تصویری پردازشی مثل Nebula، Ocean، Starfield، Aurora، Synthwave، Matrix، Bubbles، Snowfall و چند سبک دیگر
- ویرایش متن اصلی و زیرنویس
- بخش تنظیم متن برای تغییر اندازه، جایگاه عمودی، شفافیت، رنگ دلخواه، نمایش یا مخفی‌کردن زیرنویس، و جایگاه زیرنویس
- ۱۱ حالت انیمیشن متن مثل Kinetic، Cinematic Title، Typewriter، Cascade، Wave، Slam، Glitch، Blur Focus، Neon Flicker و Gold Display
- پالت رنگی، Film Grain، Vignette، تغییر Seed و حالت Multi-scene
- صدای محیطی پردازشی و امکان آپلود فایل صوتی MP3 یا WAV
- تنظیمات آماده خروجی برای YouTube، Reels و Square
- لیست ویدیوهای اخیر در همان نشست مرورگر
- کاملا آفلاین و بدون نیاز به سرور

## نحوه کار

۱. پرامپت و زیرنویس اختیاری را وارد کنید.
۲. سبک تصویر، پالت رنگ، انیمیشن متن و تنظیمات خروجی را انتخاب کنید.
۳. برنامه همه فریم‌ها را روی Canvas رندر می‌کند.
۴. صدا با Web Audio ساخته یا با فایل صوتی شما ترکیب می‌شود.
۵. مرورگر خروجی نهایی را به صورت فایل ویدیو آماده دانلود می‌کند.

## استفاده

- برای ساخت ویدیو روی **Generate video** کلیک کنید.
- با میانبر **Cmd/Ctrl + Enter** می‌توانید رندر را شروع کنید.
- هنگام رندر با **Esc** می‌توانید عملیات را لغو کنید.
- از تب **Text** برای ویرایش متن و تنظیم ظاهر آن استفاده کنید.
- از بخش **Recent videos** می‌توانید ویدیوهای ساخته‌شده در همان نشست را ذخیره یا دوباره بارگذاری کنید.

## نکته‌های آفلاین

برنامه برای رندر ویدیو هیچ API خارجی صدا نمی‌زند. همه چیز در مرورگر شما انجام می‌شود. فایل صوتی آپلودشده فقط روی دستگاه شما پردازش می‌شود و جایی ارسال نمی‌شود.

## توسعه

این پروژه با React، Vite و Tailwind CSS ساخته شده است.

```bash
npm install
npm run build
```
